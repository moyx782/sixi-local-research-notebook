# Domel：第 2 周结束原型交付记录

项目：AI-Assisted Strategic Market Analysis for Domel — Domel Electric Motors Suzhou Co., Ltd.

## 当前范围

用户确认当前处于第 2 周结束，先交付本地可运行、可部署版本；目前没有 Figma MVP。面向 Domel 苏州市场与战略团队、业务拓展和产品策略人员，并考虑总部产品规划团队的季度研究需求。

本轮复用现有 Node + SQLite 采集后端，建立研究项目、证据、发现与报告闭环。没有创建或伪造员工访谈、真实用户试用结果、Figma 版本历史、市场占有率、竞争优势或评审访问记录。

## 本轮实际迭代

1. 原界面围绕笔记/资料收集；改为以研究问题和对象为主线的八步工作区。
2. 按用户要求继续使用既有资料库、采集器、搜索、Cookie 会话及模型配置接口；没有替换采集引擎。
3. 审核由必经环节改为可跳过。跳过只影响报告包含范围，不会把待审核发现改成 Keep；Reject 始终排除，Investigate More 单列。
4. 增加 Domel 工业电机市场模板：市场边界、地域、季度、客户应用、七类研究维度。
5. Evidence 增加一级/二手来源标签、可信度与局限、涉及对象和细分；这些是评估记录，不代表系统保证来源正确。
6. Findings 增加竞争对比、客户需求、情景假设、对 Domel 的影响及战略建议。
7. 五项吸引力评分要求逐项理由与引用。原型权重为需求 25%、发展潜力 20%、竞争有利度 20%、进入可行性 15%、战略匹配度 20%；单项 1–5 分。五项齐全后，总分 = Σ(分项/5 × 权重)，范围 20–100。缺项不计算总分；这些权重尚未经团队验证。
8. 本地部署加入账号认证；研究成员共享本机资料，管理员负责账号、模型配置和 Cookie 变更。后台采集独立运行。

## 工程验证与人工验证的区别

自动化验证涵盖采集与重启恢复、登录和权限、证据原文匹配、AI 输出格式与引用过滤、市场框架持久化、评分校验和报告纳入规则。AI 测试使用可控响应，不等同于实模内容质量验收。

浏览器验证在正式资料库副本中完成：使用现有 Domel 720 公开产品资料，创建研究、提取证据、保存发现、跳过审核生成报告、返回 Keep 审核、查看竞争对比和战略建议、验证不完整评分提示、登录。一个坏链接不会阻止后续有效链接提交。移动宽度下确认页面无横向溢出。测试记录与测试账号不写入正式资料库。

## 反思与下一轮重点

### 同日追加：自动搜集、人工补采与资料库直传

- 本地发布版本更新为 `20260919T095550571Z-11504`；工作目录与发布副本均通过 55 项自动化测试。
- 新建研究可自动规划查询、搜索、筛选与采集；登录、正文提取失败及 PDF 下载需求可形成独立人工补采任务，其他采集继续运行。支持记录负责人、PDF / Markdown / TXT 文件或截图、摘录和来源，并选择仅入库或同时加入研究。
- 全部资料库新增“上传资料”，不要求先建立研究。支持 Markdown、TXT、文字 PDF、PNG/JPEG/WebP 和直接粘贴文字；文件保留原件，可在资料库阅读后加入研究。图片仅保存与展示，没有执行 OCR。
- 隔离浏览器验证完成 Markdown 直传、原件入口、自动采集遇到登录页仍继续、人工补采负责人保存、截图与文字仅入库，以及截图阅读；测试资料未写入正式库。
- 已使用用户配置的 DeepSeek 完成真实连接测试。正式研究的一次实际运行由 AI 生成 6 组查询并筛选来源，找到 47 个候选、选择 8 个，7 个采集成功（含 1 个复用来源），1 个因无法提取正文转人工补采。此结果证明真实调用与流程连通，不代表来源事实或研究结论已通过人工核验。
- 实际抽查发现同名无关网站，已将其从当前研究移出并补充相关性过滤；原始资料仍留在资料库。筛选存在误选和漏选可能，来源评估与 Evidence 核实仍需保留。

当前原型让研究判断具备结构与出处，但出处可追溯不等于结论正确。厂商产品页可支持规格或产品定位，不能单独证明市场吸引力或相对竞品优势；模型必须保留这个区别。

跳过审核降低流程阻力，同时保留“未人工审核”标签，避免把操作便利误作可信度背书。评分必须显式展示缺口，否则一个看似精确的总分会掩盖证据不足。

下一轮优先用 Domel 员工真实任务核实维度、评分依据和对比字段，再做更多自动化和定时调度。季度计划目前是研究记录；RSS 与 URL 由用户触发抓取，系统没有宣称已开启无人值守季度调度。

新增 7 项 MinerU 测试，整体 62 项测试；涵盖配置脱敏、认证、上传/轮询/Markdown 入库、缺少 Token 不阻塞、重启恢复、原件保留、人工补采关联、错误脱敏、ZIP 限额和过期上传地址重试。浏览器隔离环境实际操作验证缺少 Token 保留原件、配置及连接反馈、重试后入库、阅读 Markdown 表格与原图下载入口。云响应使用测试替身，不代表真实 MinerU OCR 质量验收；用户尚需在设置页填入有效 Token 后完成实云调用。


### MinerU 真实云服务验证（2026-09-19）

用户填写 Token 后，官方上传接口连接测试返回 200。随后在隔离资料库提交一页自制测试 PDF，使用 VLM 完成真实文件上传、云端解析、结果 ZIP 下载、Markdown 提取及入库，全程约 7.5 秒。成功识别测试字段 `250 W` 与 `48 V`，原件字节校验一致。测试没有向 MinerU 提交正式业务资料，隔离资料库与临时 Token 副本已清理。此验收覆盖简单单页 PDF 连通流程，尚不代表复杂扫描件、中文表格或截图的识别准确率。
