# 数据搜集后端

目标是让来源采集、正文提取、持久化和检索能够脱离界面、脱离模型密钥独立工作。第一版沿用 Node HTTP 服务，采用本机 SQLite，不引入外部数据库或队列服务。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `server.mjs` | HTTP、请求体限制、静态文件白名单、生命周期 |
| `backend/api.mjs` | 采集、来源、资料查询接口 |
| `backend/input.mjs` | 输入校验、URL 和正文规范化、应用错误 |
| `backend/fetch.mjs` | 有界下载、重定向、网络重试、DNS 校验和 Fake-IP 兼容 |
| `backend/parsers.mjs` | HTML 正文、RSS/Atom 条目解析，不执行脚本 |
| `backend/collector.mjs` | 持久化任务消费、单条结果、摘要降级和恢复 |
| `backend/store.mjs` | SQLite 事务、正文去重、来源关联、查询 |
| `backend/instance-lock.mjs` | 数据目录单实例锁，在恢复任务之前获取，退出或崩溃时释放 |
| `backend/cookie-sessions.mjs` | 会话校验、HTTPS 来源绑定、到期和需要登录状态；更新串行化 |
| `backend/keychain.mjs` | macOS 钥匙串存取；stdin 传递凭据，长数据分块，切换引用前验证写入 |
| `backend/login-detection.mjs` | 常见登录路径、密码表单和登录标题识别，不执行脚本 |
| `scripts/cookies.mjs` | 隐藏输入 Cookie、查看元数据和移除会话的本机 CLI |
| `backend/assistant.mjs` | 保持已有配置与上下文 AI 问答接口 |
| `backend/model-connection.mjs` | 显式协议与 Endpoint 的模型传输边界：Chat Completions / Anthropic Messages |
| `backend/discovery.mjs` | 持久化自动检索任务、规则/AI 规划筛选、采集队列协调与重启恢复 |
| `backend/handoffs.mjs` | 不阻塞自动采集的人工补采任务，负责人、文件或截图、出处和文字记录 |
| `backend/mineru.mjs` | MinerU 官方云适配器、独立 Token 配置、受限 ZIP Markdown 读取 |
| `backend/upload-parser.mjs` | 持久化上传解析状态、远程批次恢复、重试与入库衔接 |
| `backend/uploads.mjs` | 无项目依赖的资料库上传，原文件与图片保留及认证下载 |
| `scripts/local-service.mjs` | 独立版本部署、部署前检查和备份、macOS launchd 生命周期 |

`POST /api/collections` 校验输入后，将来源和任务在同一事务中写入数据库，并返回任务 ID。单个工作循环领取任务，通过 fetcher 获取资源，由解析器输出正文，最终事务写入资料及出处。状态查询能读取处理中已经完成的条目。

fetcher 通过构造参数注入，因此自动化测试不请求公网，不依赖真实 AI 密钥。HTTP 测试在临时数据目录和随机端口运行。

## 数据模型

模型配置向后兼容原有内置适配器。显式协议使用独立 HTTP 适配器，不依赖 SDK 的模型枚举；服务端规范化 Endpoint、校验 HTTPS 与公网地址、固定 DNS、禁止携密钥跳转，设置 120 秒超时与 2 MB 响应上限，失败不自动重试。只提取最终正文，空输出和截断输出均失败，不把上游原始错误或密钥写入响应。连接测试使用当前表单的短消息，限管理员且不读研究资料、不保存配置。切换连接目标会清除旧目标密钥；模型变更可保留密钥。`frontend/model-settings.js` 管理预设与表单，正式调用与连接测试复用同一传输边界。

- `sources`：来源类型、地址、标签和再次采集时使用的参数。网页和订阅按类型、URL 与会话编号唯一，手动文本按正文和出处唯一。
- `jobs`：任务输入快照、状态、结果、错误和时间。同一来源最多一个排队或运行任务。
- `documents`：由规范化正文 SHA-256 标识的不可变正文。相同正文共用资料 ID。
- `origins`：来源与条目地址的最新资料映射，包括作者、时间、质量标记、原始响应和跳转地址。来源更新不会修改其他来源已关联的正文。
- `cookie_sessions`：会话编号、HTTPS 来源、标签、状态、可选到期时间与版本号；不包含 Cookie 值。Cookie 与版本号保存在钥匙串。异步请求只能把自己使用的版本标记为失效，避免旧请求覆盖刚更新的会话。
- `research_discoveries`：规划、查询完成状态、候选与选择理由、采集 jobId 的快照。运行状态在重启时恢复排队；人工任务没有反向阻塞条件。
- `research_handoffs` / `research_screenshots`：人工任务、处理人和原图，与采集 sourceId 相连；截图不伪装为机器提取的正文。
- `library_uploads`：原文件字节与上传元数据，文字进入既有采集队列；附件通过 origin 的 sourceId 关联资料，免于依赖特定研究项目。

正文发生变化后生成新资料 ID，旧正文保留。当前版本只保留每个来源地址的最新原始响应；完整抓取历史可在后续独立增加快照表。资料检索是参数化 SQL 的字面子串匹配，支持中文，适合本地初期资料量；更大规模可替换为专门的检索索引。

SQLite 使用 WAL、外键和事务。启动前在独立 `instance.sqlite` 上持有排他事务，强制单进程独占数据目录；操作系统在进程崩溃时自动释放锁。没有实现分布式任务或周期调度。停止时中断网络任务并将其重新排队。崩溃后的运行任务在下一次启动时恢复。

## 内容与网络边界

HTML 由 [Mozilla Readability](https://github.com/mozilla/readability) 和 jsdom 提取正文，保持 jsdom 默认的脚本与子资源禁用设置。原始响应以 JSON 字符串提供，不作为静态页面开放。RSS/Atom 拒绝 DTD / 实体声明。

请求只允许 HTTP(S) 且不带 URL 登录凭据，阻止本机、内网及保留 IP；DNS 校验结果直接交给 socket，避免再次解析造成重绑定。重定向逐跳重新检查，下载、重试和响应大小均有边界。

会话请求每次读取钥匙串并检查绑定的精确 HTTPS origin。跨 origin 跳转终止；RSS 外站条目不携带会话。401/403 和识别出的登录页面触发 AUTH_REQUIRED；采集器跳过受限条目，继续公开条目和后续排队来源，不等待用户操作，不保存登录响应或用 RSS 摘要掩盖认证失败，已保存条目不回滚。同一任务里失效或钥匙串不可用的会话只尝试一次，后续同会话条目直接记录 skipped；来源级错误也会结束当前任务并消费下一个任务。普通传输错误对已认证请求使用通用错误消息，避免将请求详情写入任务记录。网页正文和原始响应仍作为用户资料保存，属于登录后可能获得的私有内容。

钥匙串写入与 SQLite 不共享事务：先写并验证新凭据，再更新数据库版本号；若进程在中间退出，版本不匹配会要求重新录入，不会继续使用错误凭据。长数据使用唯一版本的分块项目，成功切换后清理旧块；崩溃在分块写入或清理阶段可能留下不再引用的钥匙串项目。当前没有孤立项目自动清理器。后端只访问本应用数据目录命名空间内的项目，不扫描其他应用凭据。

本机服务默认监听 loopback，局域网模式可通过 `SIXI_BIND_HOST=0.0.0.0` 监听网卡；服务仅允许 loopback 和当前网卡地址的 Host/Origin，拒绝 `Origin: null`（包括外站沙盒 iframe 和 file:// 页面）。认证面向受信任的本地或局域网原型，不是面向公网的多用户部署方案。

采集内容只写本地资料库，不自动成为模型上下文。后续前端或 Agent 接入时，应显式选择资料 ID，引用其出处和质量标记。

## 后续扩展点

新来源连接器可以返回 `{title,text,url,author,publishedAt,quality}` 与原始资源，复用现有入库逻辑。关键词搜索可作为“发现 URL”前置步骤，PDF/本地文件可作为新的解析适配器，周期调度只需向现有来源提交任务。

测试覆盖解析、网络边界、正文去重、来源更新、摘要降级不覆盖完整正文、任务恢复、HTTP 查询和输入错误，以及旧 AI 配置接口兼容。额外的子进程测试覆盖 SIGTERM/SIGKILL 后恢复与去重、第二实例拒绝且不改动原任务，以及数据库完整性。


## 研究工作区与来源校验

`backend/research.mjs` 在同一 SQLite 中增加 `research_projects`，以受限操作维护项目 JSON。同步变更通过事务执行；AI 的异步阶段结束后再次校验研究范围，避免旧范围结果写入新问题。来源任务与资料正文继续使用现有表和采集器，`frontend/` 只负责真实状态的展示和操作。

Evidence 必须匹配已关联资料中的连续原文，保存不可变 documentId 和当时的来源快照；来源更新后仍保留旧证据依据。AI 候选必须经同样校验，新增 Evidence 待确认；Findings 仅引用此研究中已确认的证据。服务过滤幻觉引用不等于语义正确性验证，后者仍需真实用户与多来源核查。

研究范围包括工业电机市场边界、区域、季度、细分、七类维度及访谈/持续跟踪计划。AI 上下文只包含选中资料（前 30,000 字）或前 40 条已确认 Evidence，以及引用在这些证据内的前 10 条既有评分；每次最多产生 5 个候选。测试注入 ask 函数，不发送真实模型请求。

报告有两种明确模式：Keep-only，或显式 skipReview 纳入 draft。后者不修改审核状态；Reject 不进入报告，Investigate More 进入待调查部分。报告页面和 Markdown 使用同一次 API 返回的项目快照。数据在数据库中保留，生成报告可重新执行，导出文件由用户保存。

`backend/scoring.mjs` 验证每项 1–5 分、理由、引用。权重固定且版本化为 prototype-v1，五项齐全才算总分。它是待业务验证的决策记录，不是对市场的客观预测。

`backend/pdf.mjs` 用 PDF.js 解析有文字的文件，再通过原采集队列作为文本来源入库。不执行文件中的脚本；保留分页标记，不保存原 PDF 二进制，不做 OCR。部署包含 PDF.js 依赖与前端所有模块。

## 本地认证

`backend/auth.mjs` 管理 team_users / team_sessions。正式部署默认 SIXI_AUTH_REQUIRED=1；测试和显式开发可关闭认证。首次管理员创建为本机初始化流程，已有账号后关闭 setup；研究成员共享工作区，模型/会话/账号变更限定管理员。会话令牌只以摘要入库，浏览器 Cookie 为 HttpOnly + SameSite=Strict，登录失败限速。用户名和密码通过参数验证，数据库仅保存 scrypt 密码哈希与盐。

认证不改变队列生命周期。无登录浏览器仍可完成已排队任务，超时或退出会话不会等待用户。为保持本机 Cookie CLI/验收工具兼容，数据目录持有 0600 的 local-client-token，仅向指定 loopback HTTP 地址发送；不用于第三方采集目标。health 保留无认证的运行计数检查，其余资料/API 受保护。该实现不是公网部署完成的声明。


### MinerU 解析边界

资料库上传可显式选择 `mineru`。文件先写入 `library_uploads`，解析元数据与远程批次保存在同一记录，独立工作器推进状态，不占用常规网页采集队列。原件在 Token 缺失、网络错误及解析失败时仍可下载；可手动重试，重启恢复已提交批次。云解析完成后，Markdown 加入原采集队列，sourceId 关联原件；人工补采可在此时追加到指定研究。

独立 `mineru.json` 存储 Token，原子写入、权限 0600。固定官方 API，密钥只附在 API 请求上，不附在签名上传/下载请求。所有外部地址限定公共 HTTPS，DNS 固定、禁止跳转，响应与解压文字有大小上限。ZIP 仅在内存读取 full.md，文本在前端转义显示。历史本地资料重新解析会生成新记录，保留原文字及其引用。
