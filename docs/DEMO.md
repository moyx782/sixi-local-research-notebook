# 本地原型演示：约 7 分钟

## 准备

运行 `npm run deploy:local`，打开 `http://127.0.0.1:4173`；局域网模式请使用 `npm run service:status` 输出的 URL。首次打开由实际使用者创建管理员账号；密码至少 10 位。管理员可在“AI 设置 → 管理团队成员”添加研究成员。

选择专用演示项目，不修改已审定的研究。没有模型密钥时完整演示手动证据与发现流程；有密钥且获准使用数据后，再演示 AI 候选证据与发现。不得把预制结果说成现场 AI 输出。

## 演示路径

1. **研究定义（45 秒）**：输入“Domel 720 电机的公开资料支持哪些应用判断？”，选择公司 Domel，展开市场框架，填写工业电机市场、区域、本季度、客户应用细分。
2. **信息源与采集（60 秒）**：从现有资料库加入 Domel 720 公开产品页，或通过 URL 采集 `https://www.domel.com/product/720-inner-runner-motor-24`。展示 Search、RSS、Markdown、PDF 和 Manual Capture 入口。说明网络失败、需要登录会跳过对应来源，不等待用户操作。
3. **Evidence（60 秒）**：打开正文，选择原文摘录并说明其局限。将厂商直接发布的资料记录为一级资料，同时说明它不是独立性能测试。AI 摘录若启用，会先作为待确认候选；伪造原文无法保存。
4. **对比与判断（90 秒）**：用确认的证据建立一条带引用的发现，填写对象、客户应用、对 Domel 的影响和后续核实建议。切换竞争对比、客户需求及战略视图。缺少竞品资料时明确展示缺口，不创造竞品数据。
5. **评分与情景（45 秒）**：展示五项权重、评分理由和 Evidence 引用。只填写有依据的分项；缺项时总分显示待补充。情景必须说明假设与可观察信号。
6. **可选审核与报告（60 秒）**：直接跳过审核生成报告，展示“未人工审核”标签；返回审核可 Keep / Reject / Investigate More。导出 Markdown；打印按钮可调用浏览器打印或另存 PDF。
7. **收尾（30 秒）**：说明本地版本、实模与真实用户验收边界，展示季度访谈和持续跟踪计划。
